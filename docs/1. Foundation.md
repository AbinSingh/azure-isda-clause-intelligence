# What have we implemented so far?

A. text_normalization.py

Prepares the extracted text for structural parsing.

It handles:

    Markdown emphasis markers.
    Nonbreaking spaces.
    Simple Markdown tables containing section headings.
    Repeated blank lines and horizontal page separators.

For example, this input:

| **2.** | **Obligations** |
| ------ | --------------- |

becomes:

    2. Obligations

We will improve this module later to handle page headers, footers, and more complex extraction artifacts.

# B. marker_detection.py

Recognizes potential structural markers such as:

    2. Obligations
    (a) General Conditions
    (i) Each party will make each payment...
    (1) promptly notify the other party...
    (A) the failure by Y...

At this stage, the module identifies candidate markers. It does not assume that every marker automatically represents a new clause.


# C. structural_parser.py

Begins building the document hierarchy.

For your sample, it detects sections such as:

    Section 1 — Interpretation
    Section 2 — Obligations

Within Section 2, it identifies top-level clauses such as:

    Clause (a) — General Conditions
    Clause (b) — Change of Account
    Clause (c) — Netting of Payments
    Clause (d) — Deduction or Withholding for Tax

It also preserves the associated source text.
