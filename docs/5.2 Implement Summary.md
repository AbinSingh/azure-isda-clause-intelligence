# Clause Matcher Pipeline — Execution Order

Once Azure AI Document Intelligence returns the extraction result, the pipeline follows this order:

| Step | File                                                      | Purpose                                                                           |
| ---- | --------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 1    | `app/services/document_intelligence.py`                   | Extract document text and layout using Azure `prebuilt-layout`.                   |
| 2    | `app/services/document_parser.py`                         | Normalize the Azure output into structured paragraphs and metadata.               |
| 3    | `app/models/clause.py`                                    | Defines the `Clause` data model.                                                  |
| 4    | `app/schemas/isda_clause_registry.json`                   | Defines the expected ISDA clause structure, numbers, and titles.                  |
| 5    | `app/services/clause_registry.py`                         | Loads and indexes the registry for clause lookups.                                |
| 6    | `app/services/clause_matcher.py`                          | Matches paragraphs to clauses, builds the hierarchy, and accumulates clause text. |
| 7    | `test_clause_matcher.py` / `test_real_document_parser.py` | Validate clause matching and test against real document extraction.               |


Big Picture

    Azure Document Intelligence
              ↓
    Document Parser (normalize output)
              ↓
    Clause Model + Clause Registry
              ↓
    Clause Registry Loader
              ↓
    Clause Matcher
              ↓
    Structured Clause Hierarchy
              ↓
    Tests and Validation

# Key distinction: 

clause.py defines the structure of a clause; isda_clause_registry.json defines the expected clause 
hierarchy; clause_registry.py loads that hierarchy; and clause_matcher.py uses it to organize the extracted document 
text into clauses.
